# Factories seller outreach — manual send list

Goal: ask each photo-only seller (no buy-link in their Yupoo) whether they hand
out a Weidian / Taobao / 1688 link so we can order through an agent. Keep the
ones who say yes (like HappyWhale), drop the rest from the factories index.

## How to use this (read first)

- **Send from your own phone, by hand, a few a day.** Do NOT bulk-blast from a
  fresh WhatsApp Web session. That is what got the account restricted last time.
  Spread these over a couple of days.
- **Tap the link** in the "Send" column on your phone. It opens WhatsApp with the
  message pre-filled to that number. Read it, then hit send.
- **Do not put these sellers in one group.** They are competitors; a group would
  expose every number to every other seller.
- Some have a second number listed as a fallback if the first bounces.
- Tick the checkbox when you have sent it; note the reply in the last column.

## The message (already baked into every link below — here to copy if you need it)

> Hi! We run a group-buy shop and order through an agent (Superbuy / CSSBuy). Do
> you provide a Weidian, Taobao or 1688 link for your items so we can order that
> way? If yes, we would love to buy regularly. If you only sell direct, no
> problem. Thanks!

## 3. After you hear back

- **Says yes / sends a link** → tell me, I add their buy-links and keep them in
  the factories index (like HappyWhale).
- **Direct-sale only / no reply after a few days** → we prune them from the
  index. My lean is to drop the pure eyewear + single-brand belt catalogs first
  (most friction, least used) and keep the big multi-brand ones.
